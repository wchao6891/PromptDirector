## Where you can capture

**Open a work, post or article → Capture → Preview and select → Save cases.**

| Where inspiration lives | What you can bring with you |
| --- | --- |
| **Jimeng · Higgsfield · LiblibAI · Krea · LibTV** | Work images, videos and publicly available prompts or creative details. Keep the visual and its context together. |
| **Midjourney** | Save the selected work, public prompt, parameters and video cover; capture loaded previews from Explore. |
| **HeyBox / 小黑盒 · WeChat articles** | Save a whole article or split clearly structured multi-case posts into selectable image-and-prompt groups. Keep a single HeyBox image gallery with its prompt from the post body. |
| **Feishu documents** | Capture document bodies, long documents and images within tables, preserving cell placement and merged cells. |
| **X / Twitter · Xiaohongshu · Weibo · Reddit** | Collect the current post's text and accessible media, including prompts shared by the author. |
| **Pinterest · Behance · ArtStation · Huaban · ZCOOL** | Bring visual work into one place to browse, search and organize. |
| **More webpages and local files** | General webpage capture, text and image selection, screenshots and local imports help gather scattered materials. |

**One article, many references.** For articles with clear case headings or numbering, preview the detected groups under **Cases in article**, pick the cases you want and save each one separately, or keep the whole article for context.

**Context stays with the reference.** Multi-image works stay grouped, articles keep their media order and Feishu tables keep their layout. Media, text, original prompts, sources and later analysis each have their own place.

Capture, browsing and organization require no AI service. Pages must be accessible and original prompts must be public. Login state, lazy loading and site changes can affect results, so preview before saving. See the [capture guide](docs/CAPTURE_SUPPORT.md).

## Let your Agent take it further

Connect your library to **Codex, Claude Code or WorkBuddy**. Your Agent can search references, read prompts, retrieve originals, capture URLs and save creative materials back to the library.

1. In the extension, open **Settings → Agent connection** and select **Copy connection request**.
2. Paste it into an Agent with local MCP support. It installs, configures and verifies the connector.
3. Enable the connection in Chrome when prompted.

> “Find character-poster references in my library and list a few options for me to choose.”
>
> “Read the selected cases' original images and prompts, then use them to draft this campaign's visual direction.”
>
> “Save the approved prompt and generated images back to PromptDirector.”

Other local MCP clients can use the generic configuration. Cloud-only workspaces can't use this local flow. [Agent setup guide →](connector/INSTALL.md)

## A library that grows with you

| What your next project needs | What your library provides |
| --- | --- |
| **A reference you can recognize at a glance** | An image-first case wall, text search and tag filters. |
| **A focused collection for each project** | Nested projects, related cases and batch management. |
| **Experience you can reuse** | The Composer reads selected cases and drafts editable prompts, reusable Skills and tag suggestions for your review. |
| **Room for more than images** | Local images, videos, audio, DOCX, PDFs, Markdown, TXT, HTML, RTF and timestamped video notes. |
| **A collection you can share and preserve** | Export cases or project subtrees, full folder backups, recovery on another computer and encrypted folder sync. |

AI analysis is optional and uses your own service. Only selected or explicitly requested original images are sent to a model.

## Your library stays yours

Cases, media, tags and settings are stored in your browser by default. No account, ads or usage analytics. AI features are opt-in and use your own keys. Read the [privacy policy](store/PRIVACY_POLICY.md).

## Install

**Recommended: [Chrome Web Store](https://chromewebstore.google.com/detail/iahakaahijddcjjldidbclicedibgpjm).** Updates are automatic.

<details>
<summary>Install from GitHub (developer mode) and update in place</summary>

1. Download `PromptDirector-<version>.zip` from the [latest release](https://github.com/wchao6891/PromptDirector/releases/latest).
2. Extract it into a permanent folder named `PromptDirector` (no version number). `manifest.json` must be at the top level.
3. Open Chrome or Edge's extension page, enable **Developer mode**, select **Load unpacked** and choose that folder.

**Updating:** In Settings, check for updates and select the local upgrade action. On first use, authorize the folder Chrome currently loads and keep that location. The extension downloads, verifies and installs the update, then restarts. Your cases and media stay in the same browser library.

</details>
