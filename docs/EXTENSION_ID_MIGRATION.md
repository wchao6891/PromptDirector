# 扩展身份迁移

Chrome 会把扩展资料绑定到浏览器配置和扩展 ID。更换为另一个扩展 ID 时，新版无法直接读取旧版本地资料。

## 安全迁移

1. 保持旧扩展已安装，不要先卸载。
2. 在旧扩展的“更多 → 备份与同步”创建完整资料夹备份。
3. 打开备份目录，确认包含完成标记和媒体文件，并记录资料库显示的案例数量。1.19.2 及之后创建的新备份还会包含回收站案例和项目，并把可读取的本机链接原件复制成可恢复文件。
4. 安装新扩展，在“备份与同步”中选择刚才的完整资料夹备份恢复。
5. 随机打开多个案例，核对文字、媒体和项目关系；确认无误后再移除旧扩展。

完整资料夹备份只有在全部核心素材写入、回读和完整性检查通过后才会生成完成标记。任一本机链接或本地媒体无法读取时，本次资料夹不会被视为有效备份；请重新授权或重新定位对应文件后再创建备份。

如果旧扩展已经卸载且没有完整资料夹备份、同步目录或完整浏览器配置备份，Chrome 可能已经清除了旧数据，无法由新扩展恢复。

正式发布包必须使用 Chrome Web Store 为该项目分配的稳定身份。`npm run package:release` 会在缺失时停止发布；普通 `npm run package` 仅用于开发验证。
